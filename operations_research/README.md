A sample of operations research tasks I've done using SciPy, with some NumPy and Pandas for vectorized operations.

| File | Description | Algorithms used |
| ------------- | ------------- | ------------- |
| **[Project - travelling transporter problem](Project%20-%20travelling%20transporter%20problem.ipynb)** | Given a list of trips with some start and end times and locations, assign trips to vehicles to maximize the number of trips per vehicle. This is a bigger project for which I also wrote [a report](Project%20-%20travelling%20transporter%20problem.pdf) | Integer programming, greedy algorithm |
| **[Assign firetrucks to districts](Assign%20firetrucks%20to%20districts.ipynb)** | Assign firetrucks to a subset of districts to minimize the maximum firefighting time | Integer programming, greedy algorithm |
| **[Assign jobs to machines](Assign%20jobs%20to%20machines.ipynb)** | Given a list of processing times for jobs, assign those jobs to machines to minimize the maximum machine utilization | Integer programming, greedy algorithm |
| **[Fit linear regression](Fit%20linear%20regression.ipynb)** | Given a list of points, find the line that best fits those points (minimizing the sum of square errors) | Nonlinear programming |
| **[Portfolio optimization](Portfolio%20optimization.ipynb)** | Given a list of prices, expected prices and variance, decide how much should be invested into each stock to minimize variance while reaching some target revenue | Nonlinear programming |
| **[Solve maximization problems](Solve%20maximization%20problems.ipynb)** | Solve a few abstract maximization problems | Linear programming, integer programming with manual branch-and-bound |
