A variety of miscellaneous data science exercises I've done in the past.

Each Jupyter notebook analyses and models various parts of its own dataset. These mostly use pandas and numpy for data analysis, scikit-learn for modelling, and matplotlib (with some seaborn) for visualisation.

| File | Description | Models used |
| ------------- | ------------- | ------------- |
| **[Analyse and model house sales data](Analyse%20and%20model%20house%20sales%20data.ipynb)** | Analysis of housing data and modelling to predict the price from a set of descriptive features such as number of floors or square feet. | Linear Regression, Ridge Regression, Grid Search |
| **[Bike sharing analysis](Bike%20sharing%20analysis.ipynb)** | Analysis of bike sharing data and modelling to predict the number of bicycles used per day. | Random Forest Regression, Grid Search |
| **[Determine importance of sensor features](Determine%20importance%20of%20sensor%20features.ipynb)** | Analysis of sensor features to determine how important each are for predicting the label. | Support Vector Classification |
| **[Predict appliances with energy data](Predict%20appliances%20with%20energy%20data.ipynb)** | Analysis of energy data and modelling to predict number of appliances being used for each hour. | Random Forest Regression |
| **[Predict blood donations](Predict%20blood%20donations.ipynb)** | Modelling to predict whether someone donated blood. | Random Forest Classification |
| **[Predict passenger quantity](Predict%20passenger%20quantity.ipynb)** | Analysis of public transport passenger quantity data and modelling to predict number of passengers. | Random Forest Classification |
