A variety of miscellaneous data science exercises I've done in the past.

Each Jupyter notebook analyses and models various parts of its own dataset. These mostly use pandas and numpy for data analysis, scikit-learn for modelling, and matplotlib (with some seaborn) for visualisation.

- **Analyse and model house sales data:** Analysis of housing data and modelling to predict the price from a set of descriptive features such as number of floors or square feet. Uses linear and ridge regression for modelling and grid search for hyperparameter tuning.
- **Bike sharing analysis:** Analysis of bike sharing data and modelling to predict the number of bicycles used per day. Uses random forest regressor for modelling and grid search for hyperparameter tuning.
- **Determine importance of sensor features:** Analysis of sensor features to determine how important each are for predicting the label. Uses a support vector classifier for modelling.
- **Predict appliances with energy data:** Analysis of energy data and modelling to predict number of appliances being used for each hour. Uses random forest regressor for modelling.
- **Predict blood donations:** Modelling to predict whether someone donated blood. Uses random forest regressor for modelling.
- **Predict passenger quantity:** Analysis of public transport passenger quantity data and modelling to predict number of passengers. Uses random forest regressor for modelling.
