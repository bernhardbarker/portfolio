Various small generative AI and deep learning projects I've done using Watson, OpenAI, Hugging Face and PyTorch.

| File or directory | Description |
| ----------------- | ----------- |
| **[Classify and caption images](Classify%20and%20caption%20images.ipynb)** | Classify and caption images using a Keras VGG16 model and BLIP transformers |
| **[Classify documents](Classify%20documents.ipynb)** | Classify documents using a neural network with PyTorch and torchtext |
| **[Answers questions about documents](answers_questions_about_documents.py)** | A bot that answers questions about uploaded documents using RAG and LangChain |
| **[Image captioning](image_captioning.py)** | Image captioning tool using the BLIP model from Hugging Face's Transformers |
| **[English-to-Spanish translator](english_to_spanish_translator)** | Voice and text English-to-Spanish translator tool using watsonx's Mistral Large and Watson Speech Libraries for speech-to-text and text-to-speech. |
| **[Voice and text chatbot](voice_and_text_chatbot)** | Voice and text chatbot using OpenAI's GPT-3 and IBM Watson Speech Libraries for speech-to-text and text-to-speech. |
| **[Simple chatbot](simple_chatbot)** | Simple chatbot using Hugging Face's Transformers. |
